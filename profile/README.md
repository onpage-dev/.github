## Open-source projects

### Libraries

| Project | What it does | Install |
| --- | --- | --- |
| [onpage-php](https://github.com/onpage-dev/onpage-php) | Query your On Page® data from PHP with an API token | `composer require onpage-dev/onpage-php` |
| [onpage-js](https://github.com/onpage-dev/onpage-js) | The same for JavaScript and TypeScript | `npm install onpage-js` |
| [onpage-widgets](https://github.com/onpage-dev/onpage-widgets) | Lets the visitors of your website browse On Page® data | a `<script>` from jsDelivr |

### Integrations

| Project | What it does |
| --- | --- |
| [wordpress-plugin](https://github.com/onpage-dev/wordpress-plugin) | WordPress receives and keeps in sync the structured data of an On Page® project, through a REST API |
| [woocommerce-onpage](https://github.com/onpage-dev/woocommerce-onpage) | Imports an On Page® project snapshot into a WooCommerce shop |
| [laravel-plugin](https://github.com/onpage-dev/laravel-plugin) | Brings On Page® data and its structure into a Laravel application |

### Apps

| Project | What it does |
| --- | --- |
| [op-media-downloader](https://github.com/onpage-dev/op-media-downloader) | Keeps a folder in step with the media files of an On Page® project: a desktop app for Windows, macOS and Linux, a command line for servers and MCP for AI agents |
